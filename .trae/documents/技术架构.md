## 4. 数据模型

### 4.0 离线交接与版本控制

为解决"巡查员离线改档、整份导入覆盖他人修改、不知是谁改的"问题，档案库内置乐观并发与三方合并：

- **稳定编号 `id`**：长椅终身编号，跨设备/跨交接文件不变，合并按编号归并。
- **修订号 `rev`**：初始为 1，每次落盘修改 +1；保存时带 `expectedRev`，与主档当前修订号不一致即拒绝（`SaveConflictError`），后到的页签看到版本冲突并可加载最新版本。
- **修改人 `lastEditor` / `lastDevice`**：每次写入记录巡查员姓名与设备编号。
- **交接文件（bench-handoff v1）**：每条长椅携带 `benchId`、`baseRev`、当前快照 `bench` 与共同基准 `baseSnapshot`。
- **三方合并（`utils/merge.ts`）**：以 base/local/incoming 逐字段比对——
  - 仅一方改：自动并入（对端改）或保留（本机改）；
  - 双方改不同字段：各自保留；
  - 双方改同一字段且不同：两版都进**待核对**（含时段体验按编号的字段级冲突）；
  - 离线新建并入为"未核对"；主档已删除而对端改过则恢复并入。
- **可恢复导入（`utils/handoff.ts`）**：任务逐条处理，每处理一条即把 `nextIndex/results` 落盘到 `pendingImport`；单条失败中断但已完成部分保留，重试从失败条继续（不重复写入）。
- **核对（Review）**：巡查员逐字段选用本机/离线/自定义值，填写公开备注；通过后 `rev+1`、`reviewed=true`、写入 `publicNotes`、冲突出列。
- **重算**：地图、排行、详情统计都从同一份合并后主档读取，核对通过即自动重算。
- **角色**：`inspector`（编辑/导入/核对）与 `viewer`（只能看到 `reviewed=true` 的长椅，备注仅见 `publicNotes`）。
- **迁移**：无 `rev` 的旧数据在加载时自动迁移为 `rev=1` 初始版本（历史数据默认已核对公开）。

### 4.2 字段说明

**长椅信息 (Bench)**
- `id`: 唯一标识符，UUID 格式
- `name`: 长椅名称，用户自定义
- `location`: 位置文字描述
- `lat`, `lng`: 经纬度坐标（用于地图视图占位）
- `material`: 材质（木质/金属/石质/塑料/混合）
- `orientation`: 朝向（东/南/西/北/东南/东北/西南/西北）
- `hasBackrest`: 是否有靠背
- `shadeLevel`: 遮阴情况（无/部分/完全）
- `noiseLevel`: 噪音等级（安静/一般/嘈杂）
- `stayDuration`: 适合停留时长（<15分钟/15-30分钟/30-60分钟/1小时+）
- `rating`: 综合评分 1-5
- `review`: 个人评价文字

**时段体验 (BenchExperience)**
- `id`: 唯一标识符
- `benchId`: 关联长椅 ID
- `timePeriod`: 时段（早晨/中午/下午/傍晚/夜晚）
- `notes`: 体验备注
- `rating`: 该时段评分

## 5. 舒适度计算

舒适度综合评分算法：
- 靠背权重：20%
- 遮阴权重：20%
- 噪音权重：20%
- 材质权重：15%
- 用户评分：25%

```
舒适度 = 靠背得分*0.2 + 遮阴得分*0.2 + 噪音得分*0.2 + 材质得分*0.15 + 用户评分*0.25
```
